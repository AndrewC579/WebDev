Web Technologies

HTML

HTMl stands for HyperText Markup Languag and it is the standard language used to create webpages. It acts as the structural blueprint or skeleton of a website telling your web browser where to put text, images, and links. By using special tags like h1 for headings and p for paragraphs, HTML organizes raw content into a neat and readable layout on your screen.

CSS

CSS stands for Cascading Style Sheets.it is the code used to design and style how a website looks. While HTML creates the basic structure of a webpage, CSS adds colors, fonts, layouts, and backgrounds to make it visually appealing.

JavaScript

JavaScript is a popular programming language used to make websites interactive and alive. While HTML builds the structure of a webpage and CSS handles the styling, JavaScript controls how the page behaves when you interact with it. It powers features like pop-up menus, image slideshows, and forms that submit without refreshing the page.

AFrame

A-Frame is an open-source framework used to build virtual reality experiences right inside your web browser. It allows creators to build 3D worlds using simple HTML code, making it accessible even if you do not have a background in complex game development. Because it runs on standard web technologies, the scenes you create can be viewed on ordinary computers, smartphones, or dedicated VR headsets without needing to download any special applications.
